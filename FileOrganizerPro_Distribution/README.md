# File Organizer Pro Distribution

This folder contains the distribution-ready files for File Organizer Pro, including the installer, executable, and supporting files.

## What's Included

- `install_gui.py`: GUI installer for File Organizer Pro
- `config.json`: Configuration for distribution
- `MODERN_FEATURES.md`: List of modern features
- `README.md`: This file

## Key Features

- 🗂️ Smart file categorization and organization
- 🎯 Custom category creation
- 👀 Preview mode (dry run)
- ⌨️ Keyboard shortcuts
- 🖱️ Drag & drop support
- 📊 Real-time statistics
- 📝 Activity logging
- 🎨 Modern dark theme and theme selection
- ⚙️ Settings for default folder, file type filters, theme, and log file location

## How to Use

1. Run the installer (`install_gui.py`) to set up File Organizer Pro.
2. Launch the application.
3. Select a folder to organize (default is Desktop, can be changed in Settings).
4. Use the Settings dialog (⚙️) to customize:
	- Default folder
	- File type filters
	- Theme (light/dark)
	- Log file location
5. Click 'Scan' to preview file categories.
6. Enable 'Dry Run' to preview changes before organizing.
7. Click 'Organize Files' to start organizing.

## Requirements

- Windows 7 or later (for executable)
- Python 3.7+ (for Python version)

For more details, see the main project README or MODERN_FEATURES.md.
